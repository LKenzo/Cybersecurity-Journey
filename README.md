# Cybersecurity Journey

Welcome to my personal cybersecurity knowledge vault. This repository documents my journey through various Capture The Flag (CTF) challenges, forensic investigations, and reverse engineering puzzles. 

I created this space to:
- **Solidify my learning** by writing detailed walkthroughs.
- **Share methodologies** with the infosec community.
- **Showcase my analytical process** to peers and potential employers.

---

## Repository Structure

Every challenge writeup is organized by category and difficulty. Each markdown file includes:
- **Tools used** (e.g., `binwalk`, `Wireshark`, `Ghidra`).
- **Step-by-step reasoning** (the *why* behind the commands).
- **Code snippets** and hex dumps where applicable.
- **Lessons learned** to reinforce key takeaways.
